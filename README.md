 Care2U Connect
A free, open-source mobile web app for Care2U Patient Support Service in Gombe State, Nigeria. It helps community nurses and midwives book home visits, remind clients through WhatsApp and follow up on missed care.
 What it does
- Registers clients, with consent recorded
- Books visits for services such as antenatal care, postnatal care, immunisation, wound dressing and drug delivery
- Shows overdue, today and tomorrow visits on one screen
- Opens WhatsApp with a ready-written reminder in English or Hausa
- Marks visits done or missed and prompts a follow-up booking
- Shows a monthly summary and exports data as CSV or JSON
How to use it
Open index.html in a phone or computer browser. No server or installation is needed. Data is stored only on the device, so download a backup often.
 Privacy
Do not upload exported files to this repository. They contain client information.
